# Workshop Signup Application

A modular Python application demonstrating core data structures (`list`, `set`, and `dict`) to manage event registration, attendee lookups, payment tracking, and workshop schedules.

## Core Modules

- **Registration Module (`modules/registration.py`)**: Adds new attendees, preserving order while avoiding duplicate entries.
- **Lookup Module (`modules/lookup.py`)**: Queries details for a specific registered user.
- **Payment Module (`modules/payment.py`)**: Computes summary statistics on paid and unpaid registrations.
- **Schedule Module (`modules/schedule.py`)**: Displays workshop session timelines.

## How to Run

Execute the main file from the project root:

python main.py
